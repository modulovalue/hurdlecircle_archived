## Running

The desktop version builds with current libGDX and runs natively on Apple Silicon. It needs Java 17 or newer.

```sh
./gradlew desktop:run
```

`./gradlew desktop:dist` builds a standalone jar at `desktop/build/libs/HurdleCircle.jar`. On macOS, run it with `java -XstartOnFirstThread -jar HurdleCircle.jar`.
